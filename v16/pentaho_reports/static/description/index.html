Pentaho Reports — Native Renderer

Render .prpt reports to PDF entirely inside Odoo

Design reports in Pentaho Report Designer and render them straight from Odoo with a pure-Python engine. No Java, no application server, no external report service — it runs anywhere Odoo runs, including Odoo.sh.

Key Features

  • Pure-Python renderer for .prpt files — PDF output
  • Page, report and group bands, detail rows, sub-reports
  • Dynamic height, images, custom page sizes
  • Geometry calibrated against the reference Java engine
  • SQL data sources run on Odoo's own database cursor
  • Upload .prpt files or load them from a module path
  • Direct browser printing (Chrome, Firefox, Edge, Safari)
  • Python API and JavaScript action handler

Creating a Report

Declare a report action — the .prpt file stays the source of truth:

<record id="report_invoice_pentaho" model="ir.actions.report">
    <field name="name">Customer Invoice</field>
    <field name="model">account.move</field>
    <field name="report_type">pentaho</field>
    <field name="report_name">account.invoice.pentaho</field>
    <field name="pentaho_report_output_type">pdf</field>
    <field name="pentaho_direct_print">False</field>
    <field name="pentaho_filename">my_module/reports/invoice.prpt</field>
    <field name="pentaho_load_file" eval="True"/>
    <field name="binding_type">report</field>
    <field name="binding_model_id" ref="account.model_account_move"/>
</record>

Or create it from the UI: Settings > Technical > Reports, report type "Pentaho Report", and upload the .prpt file.

Python API

report = self.env.ref('my_module.report_invoice_pentaho')
content_b64, output_type, filename, direct_print = self.env['ir.actions.report'].render_report(
    report.id, record_ids,
    {'variables': {'custom_var': 'value'}},
)
pdf_bytes = base64.b64decode(content_b64)
